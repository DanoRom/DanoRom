# Stage: Ideation

Your project is at the very beginning — an idea looking for its first artifacts.

## What this stage is about
Turning a vague concept into something concrete enough to build. The biggest risk
here is building the wrong thing, not building the thing wrong.

## Key activities
- **Write it down.** A one-page README describing the problem, the user, and the
  smallest version that would be useful.
- **Pick a stack you already know.** Novelty in the idea OR the stack — never both.
- **Sketch the data model.** List the 3–5 core entities and how they relate.

## You're ready for the next stage when
- The README exists and someone else could understand the idea from it.
- You know the first feature you will build and what "done" looks like for it.
