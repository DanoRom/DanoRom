# Stage: Maintenance

The project is live and structurally mature. The work shifts from building to operating.

## What this stage is about
Keeping the running system healthy while deciding what the next iteration is.

## Key activities
- **Monitor errors and uptime.** Free-tier monitoring catches most of what matters.
- **Patch dependencies on a schedule.** Security updates are cheaper as routine than
  as emergency.
- **Mine user feedback.** Recurring requests are your roadmap writing itself.
- **Profile before optimizing.** Measure the slowest path; fix that one, not a guess.

## Signs it's time to loop back
- A big feature request means returning to feature development — with the safety
  net you already built.
- Falling usage means returning to ideation: the problem or the audience shifted.
