# Stage: Feature Development

Real code is flowing. The danger now is speed without a safety net.

## What this stage is about
Shipping the features that make the product useful, while keeping the codebase
healthy enough to keep shipping next month.

## Key activities
- **Add tests as you go.** Cover the money paths first — the flows users depend on.
- **Keep commits small.** Reviewable changes get reviewed; huge ones get rubber-stamped.
- **Prioritize ruthlessly.** Rank the backlog by user impact, not by what's fun.
- **Refactor hotspots.** When you touch a messy file for the third time, clean it.

## You're ready for the next stage when
- The core features work and are covered by tests.
- Breaking the app is harder than fixing it.
